# 집필기

폴더 안의 `.txt` 파일로 쓰는 한국어 웹소설 집필기입니다.

- 원고는 이 저장소에 올라가지 않습니다. 원고는 각자 컴퓨터에서 고른 폴더에만 저장됩니다.
- 크롬·엣지(데스크톱)에서 열고 주소창 오른쪽의 설치 아이콘으로 앱처럼 설치해 쓸 수 있습니다.
- 사파리·파이어폭스·모바일 브라우저는 폴더 저장 기능을 지원하지 않아 쓸 수 없습니다.

## 초고 메모장 (memo/)

집필기와 별개인 아주 가벼운 txt 메모장입니다. 열기·저장·자동 저장, 글자 수(공백 포함/제외), 글자 크기만 있습니다. 주소: /memo/
